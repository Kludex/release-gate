# Security policy

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/Kludex/release-gate/security/advisories/new).
Do not open a public issue.

Include the affected version or commit, the steps to reproduce, and the impact you expect. You will get an answer
within a week.

The [threat model](docs/threat-model.md) lists what release-gate is meant to stop. A report that bypasses something in
"Protects against" is in scope.
